# outpeer-cv

Учебный проект обнаружения видимого мусора на аэроснимках.

Часть А: подготовка данных, EDA и fine-tuning YOLOv8n.
Установка, запуск и передача модели участнику Б: [инструкция](reports/a/README.md).

Начальный источник — UAVVaste, один класс `rubbish`. Результаты на этом наборе
не подтверждают качество на морских, прибрежных или спутниковых снимках.
